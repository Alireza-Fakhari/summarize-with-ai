# Security policy

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/Alireza-Fakhari/summarize-with-ai/security/advisories/new). You will get a reply within 72 hours, and a fix will be released as soon as possible with credit to you (unless you prefer otherwise).

Only the latest release receives security updates.
