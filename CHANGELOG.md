# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.1] - 2026-10-24

### Fixed
- Theme and page-builder styles (e.g. Elementor kit button styles, underlined links) no longer leak into the buttons, mode switcher and copy button.
- Elementor widget style controls still apply on top of the hardened styles.

## [1.0.0] - 2026-10-23

### Added
- One-click buttons for ChatGPT, Perplexity, Claude, Gemini, Grok, Google AI Mode, Copilot, DeepSeek, Le Chat and You.com, plus custom assistants.
- Prompt modes (summary, key points, explain simply, translate, ask) with template variables.
- Copy-prompt button and automatic copy for assistants without a prompt URL.
- Privacy-first analytics with a dashboard, insights and CSV export.
- `llms.txt` generator, UTM tagging, floating button.
- Gutenberg block, Elementor widget, shortcode and `swai_render()`.
- Persian translation.
