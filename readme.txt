Let readers summarize any post with ChatGPT, Perplexity, Claude, Gemini and more. Prompt modes, privacy-first analytics and llms.txt.

== Description ==

Summarize with AI adds "Summarize with: ChatGPT · Perplexity · Claude · Gemini…" buttons to your posts. Readers pick what the AI should do (summary, key points, explain simply, translate, ask questions) and land in their favorite assistant with your page already in the prompt.

* 10 built-in assistants + unlimited custom ones
* Editable prompt modes with {url}, {title}, {site}, {excerpt}
* Copy-and-paste fallback for assistants without a prompt URL
* Analytics dashboard: clicks, impressions, CTR, assistants, modes, devices, top posts, CSV export
* Privacy-first: no cookies, no IPs, no personal data
* /llms.txt generator and UTM tagging
* 6 styles, dark mode, live preview, floating button
* Gutenberg block, Elementor widget, shortcode and PHP function
* Translation-ready, RTL-ready, ships with Persian

== Installation ==

1. Upload the plugin zip from Plugins → Add New → Upload Plugin.
2. Activate it.
3. Configure it under Summarize AI → Settings.

== Frequently Asked Questions ==

= Does it send my content to an AI service? =
No. The plugin only builds links. The visitor's browser opens the assistant they choose.

= Does analytics use cookies? =
No. Only anonymous daily totals are stored in your own database.
